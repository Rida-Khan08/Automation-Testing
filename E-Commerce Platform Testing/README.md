## 📝 About This Project
This is a professional **End-to-End (E2E) automation testing framework** for an e-commerce platform (SauceDemo). It simulates real user behavior, from logging in to adding items to the cart, ensuring a seamless shopping experience. 

### ✨ Key Highlights:
- ⚡ **Fast & Reliable:** Powered by Playwright's auto-waiting mechanism.
- ️ **Scalable Architecture:** Uses **Page Object Model (POM)** for clean and maintainable code.
- 🔄 **CI/CD Ready:** Integrated with GitHub Actions for automated test runs.
- 📊 **Rich Reporting:** Generates detailed HTML reports after every run.

---

## 📂 Project Structure
```text
Automation-Testing/
├── pages/                 # Page Object Model (POM) Classes
│   ├── LoginPage.js       # Login locators & actions
│   └── InventoryPage.js   # Cart & Product actions
├── tests/                 # Test Scripts (Specs)
│   └── login.spec.js      # Login test cases
├── test-data/             # JSON/CSV Test Data
├── utils/                 # Helper Functions
├── package.json           # Dependencies
└── playwright.config.js   # Configuration

🏗️ POM Architecture Flow
Test File (login.spec.js) ➡️ Calls POM (LoginPage.js) ➡️ Uses Locators & Actions ➡️ Interacts with Website (SauceDemo) ➡️ Returns Test Result (Pass/Fail)
```
